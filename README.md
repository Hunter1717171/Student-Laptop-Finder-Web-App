# Student Laptop Finder

Student Laptop Finder is a simple web application for students to browse and compare laptops.

## Technologies

- HTML
- Tailwind CSS 4
- JavaScript
- JSON
- LocalStorage

## Pages

- Home
- Laptops
- Details
- Favorites
- Compare

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

npm install

4. Build Tailwind CSS:

npx @tailwindcss/cli -i ./src/input.css -o ./dist/output.css --watch

5. Open index.html using Live Server.

## Features

- Search laptops
- Filter by category, price and RAM
- Sort laptops
- View laptop specifications
- Save and remove favorites
- Compare 2 to 4 laptops
- Switch between light and dark themes
